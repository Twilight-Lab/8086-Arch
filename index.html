AX — Accumulator Register

Primary Arithmetic, Logic & I/O Accumulator (Split into 8-bit AH and AL)

AX is the preferred 16-bit accumulator in the Execution Unit. Using AX/AL often results in shorter, 1-byte machine opcodes and faster execution compared to other general-purpose registers.

CF — Carry Flag

Set to 1 if an arithmetic operation generates a carry out of or a borrow into the Most Significant Bit (D7 for byte, D15 for word). Also used in rotate and shift instructions.

Related Assembly Instructions: JC (Jump if Carry), JNC (Jump if No Carry), STC (Set CF=1), CLC (Clear CF=0), CMC (Complement CF)
16-Bit Flag Register Hex: 0202H
6 Conditional / Status Flags (ALU Set)
CF (D0), PF (D2), AF (D4), ZF (D6), SF (D7), OF (D11)
3 Control Flags (Programmer Set)
TF (D8 - Trap), IF (D9 - Interrupt), DF (D10 - Direction)
